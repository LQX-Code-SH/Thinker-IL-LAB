# 应用案例：VLA 抓取与搬运

场景定义：基于 Walker S2 EDU 探索者 人形机器人进行桌面的 VLA 整理抓取任务，将桌面零件放入收纳盒，后将收纳盒搬运到远处目标点。

实现方法：

- 使用Thinker-IL-LAB工具链训练出桌面整理的VLA模型；
- 使用推理服务器的部署方式热加载抓取模型，使用推理客户端脚本调用推理服务；
- 创建任务管理器用于机器人导航、搬运以及VLA抓取等多任务切换，完成全流程任务。机器人导航和搬运工具链使用方法（代更新）
